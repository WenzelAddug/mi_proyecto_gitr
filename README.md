# Proyecto de pruebas de Git

Ejercicio de **Entornos de Desarrollo** de 1º DAW para practicar Git y GitHub: commits, ramas, merges y resolución de conflictos.

## Archivos

| Archivo | Qué es |
|---|---|
| `index.html` | Página principal |
| `css/styles.css` | Estilos de la página |
| `funcionalidad.txt` | Archivo creado en la rama `desarrollo` |
| `.gitignore` | Ignora los `.log` y la carpeta `temp/` |

## Qué practiqué

- Crear el repositorio y hacer los primeros commits
- Trabajar en una rama `desarrollo` y unirla a `master`
- Resolver conflictos en el README entre ramas
- Sincronizar el repositorio local con GitHub (`pull` y `push`)
- Ramas y pull requests en GitHub

## Comandos que usé

```bash
git init
git add .
git commit -m "mensaje"
git branch desarrollo
git checkout desarrollo
git merge desarrollo
git pull origin master
git push origin master
```
